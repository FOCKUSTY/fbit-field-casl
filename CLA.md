## 1. Предоставляемые права

Вы сохраняете авторство на свои изменения (они остаются в истории коммитов).  
Одновременно вы предоставляете автору проекта **безотзывную, вечную, всемирную, бесплатную, неисключительную лицензию** на ваш код, включая **право сублицензирования** на любых условиях (в том числе под лицензиями, несовместимыми с исходной).

Автор проекта вправе без дополнительного согласования с вами:

- использовать ваш код в любых целях, включая коммерческие;
- изменять, адаптировать, переводить ваш код;
- распространять ваш код в составе оригинального или модифицированного проекта;
- включать ваш код в проприетарные сборки и менять лицензию проекта в будущем;
- удалять, откатывать или «ломать» ваш код без уведомления.

Вы **не можете отозвать** переданный код или запретить его использование под новой лицензией.

## 4. Согласие через бота CLAassistant

**Подписание CLA является обязательным условием для принятия Pull Request.**

Проект использует сервис [CLAassistant](https://cla-assistant.io/).  
После создания Pull Request бот оставит комментарий с просьбой явно подтвердить согласие, поставив галочку «I agree».  
Без этого действия Pull Request не может быть объединён (merged).  
Факт подтверждения фиксируется в комментариях и служит неопровержимым доказательством вашего согласия.

Автоматическое согласие «по факту отправки PR» **не применяется**. Требуется **явное действие** через интерфейс бота.

## 6. Изменения в CLA

Автор проекта может обновить CLA.  
Изменения вступают в силу через **30 дней после публикации** новой версии (`CLA.md`).  
Если вы продолжаете отправлять код после этой даты, это считается вашим согласием с новой версией.  
Серьёзные изменения (например, отказ от патентной оговорки) будут объявлены через issue с тегом `CLA-change` за 60 дней.
