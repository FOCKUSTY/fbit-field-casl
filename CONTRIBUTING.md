# Как внести вклад

Спасибо, что решили помочь проекту!  
Пожалуйста, ознакомьтесь с правилами ниже.

## Обязательное подписание CLA

**Все контрибьюторы обязаны подписать Contributor License Agreement (CLA) перед тем, как их Pull Request будет принят.**

Проект использует бота [CLAassistant](https://cla-assistant.io/).  
После создания Pull Request бот автоматически проверит, подписали ли вы CLA.  
Если нет – он оставит комментарий с кнопкой **“I agree”**.  
**Нажмите её**, чтобы подтвердить согласие с условиями [CLA.md](./CLA.md).

**Важно:**  

- Без нажатия кнопки Pull Request не может быть объединён.  
- Подпись фиксируется и сохраняется в истории репозитория.  
- Если вы уже подписывали CLA в другом PR этого проекта, повторно подписывать не нужно.

Текст CLA доступен по ссылке: [CLA.md](./CLA.md).  
Пожалуйста, прочитайте его перед отправкой кода.

## Процесс

1. Создайте issue для обсуждения крупных изменений.
2. Форкните репозиторий и создайте ветку.
3. Внесите изменения, придерживаясь стиля кода.
4. Убедитесь, что тесты проходят: `npm test`.
5. Отправьте Pull Request в ветку `main`.

## Стиль кода

- Соглашение [LAF](https://docs.laf-team.ru/agreements/general)
- TypeScript, строгий режим.
- Для форматирования используйте Prettier (конфиг в репозитории).
- Комментарии на русском или английском – по желанию, но основные сообщения коммитов лучше на английском.

## Сообщения о проблемах

При создании issue опишите:

- ожидаемое поведение,
- фактическое поведение,
- шаги для воспроизведения,
- окружение (версия Node.js, браузер и т.д.).

## Лицензия

Ваш код будет доступен под лицензией MIT и на условиях CLA.
